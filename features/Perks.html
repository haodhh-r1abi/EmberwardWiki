Mô tả

  • 132 PerkSettingData (7001–7125, 7901–7908) là hiệu ứng theo kịch bản (ePerkScenario): ENDLESS_FOR_ROUND_END (chọn buff/debuff cuối mỗi round endless: +15/20 % dmg/range/speed/crit, ban tháp, tile lava/băng, extra coin 100, quái nhanh…), ANOMALY_LEVEL (map node 'BATTLE (ANOMALY)': quái nhanh-mỏng, phantom, slime army, thunderstorm, twisted block, ban tháp hay dùng, tháp đồng tầm…), SKELETON_KING (trial), CHARACTER_ONLY (Joker Falling Blocks 7041, Snow freeze 7042), INFERNO_SHARD (7901–7908 ×3 cấp), ENDLESS_GLOBAL/BLESSING (24 Blessing 7067–7090 chọn tối đa 5 ở Custom Endless), COSMO_ACADEMY_REWARD (quà Academy W5: 7091–7125 gồm statue, feast 7105–7111 PERMANENT, trash), ALTAR pact 7061–7065.
  • Map.AddAnomalyToMapNode: ResourceManager.GetRandomPerksForRogueliteMap(count, step, type, scenario, exclude) → MapNodeData.anomalyPerkType (+extraAnomalyPerkType ở Shard Environment L3: battle thường 1 anomaly, anomaly node 2; buffAnomalyPerkType). Vào stage: PerkManager.Start → AddPerk(settingData) → AddComponentByPerkType tạo APerkBase con; list_ActivePerks; OnRoundEnd xử lý duration; list_ActivateRequirement (MORE_THAN_X_TOWER…, ACTIVATED_LESS_THAN_X_TIMES) lọc perk hợp lệ khi random; pickWeight. Endless: GetRandomPerksForEndlessMode(count, BUFF/DEBUFF, ENDLESS_FOR_ROUND_END) mỗi round; GetPositiveAnomaly/GetNegativeAnomaly/GetBlessingsForEndlessMode(seed) cho daily/weekly. Cosmo Academy: GetPerksForCosmoAcademyReward(count) khi đủ shard; cosmoPerkDuration PERMANENT giữ cả run (list_PermanentCosmoPerks) hoặc IN_STAGE_ONLY.

Mở khóa & điểm vào

Anomaly node: IsAnomalyLevelUnlocked (clear Frost Ruins) — weight ×1.5; Darkness: Heroic + đã hạ boss Normal (×1.25). Shard: clear W5. Blessing: Custom Endless.

Điểm vào:

  • MapNode anomaly icon (UpdateAnomalyIcon, node_AnomalyEffect_Duo)
  • Endless round end popup
  • Skeleton King trial cards
  • UI_AcademyPerkReward_Popup (Mysterious Shard)

Cách hoạt động

  1. Anomaly node: AddAnomalyToMapNode → 1 perk ANOMALY_LEVEL (2 nếu Shard Env L3) → Tooltip node hiện MAPNODE_BATTLE_ANOMALY + mô tả perk → Thưởng: thêm relic (RollStageReward stageType 15) → PlayerRecord.AddClearedVariantLevels (Quy tắc: Trọng số ×1.5 so với battle thường)
  2. Perk cuối round Endless: Chọn 1 buff (+dmg 15 %, range 20 %, speed 15 %, crit 20 %, tháp/relic/thẻ, chest, tile buff) kèm debuff (ban, lava/ice/corrupt tile, quái +dmg/speed, cost +10 %, mất relic, ELEMENTAL_ONLY/SPIDER_ONLY/WOLF_ONLY 3 vòng) → Requirement: ví dụ 7001 ACTIVATED_LESS_THAN_X_TIMES=5; 7012 MORE_THAN_X_TOWER=4; 7018 round ≥4 (Quy tắc: cosmoPerkDuration IN_STAGE_ONLY)
  3. Inferno Shard perk: HardModeSetting.GetPerkTypeByShardType → 7901–7909; MainGame.Start activate theo level (Perk_InfernoShard_*) → Ví dụ Shard Cannon: L1 +20 % giá cùng loại (reset mỗi vòng), L2 malfunction +50 %, L3 deploy 5 s (Quy tắc: Chi tiết trang Difficulty)
  4. Quà Academy (W5): GiveAcademyChestReward → UI_AcademyPerkReward_Popup: chọn 1 trong GetPerksForCosmoAcademyReward(count) → Feast (7105–7111) PERMANENT — achievement ALL_COSMO_FEAST_PERK_COMPLETE; trash A/B/C; statue; Philosopher Stone; Headmaster Coinbag… → List_TriggeredCosmoAcademyPerk / List_PresentedCosmoAcademyPerk tránh lặp
  5. Blessing (Custom Endless): Chọn map đã mở + tối đa 5 blessing (7067–7090) → GetBlessingsForEndlessMode(count, seed) cho daily/weekly cố định (Quy tắc: CUSTOM_ENDLESS_SELECT_MAP_SELECT_BLESSING)
Luồng chi tiết theo code

Map.AddAnomalyToMapNode: ResourceManager.GetRandomPerksForRogueliteMap(count, step, type, scenario, exclude) → MapNodeData.anomalyPerkType (+extraAnomalyPerkType ở Shard Environment L3: battle thường 1 anomaly, anomaly node 2; buffAnomalyPerkType). Vào stage: PerkManager.Start → AddPerk(settingData) → AddComponentByPerkType tạo APerkBase con; list_ActivePerks; OnRoundEnd xử lý duration; list_ActivateRequirement (MORE_THAN_X_TOWER…, ACTIVATED_LESS_THAN_X_TIMES) lọc perk hợp lệ khi random; pickWeight. Endless: GetRandomPerksForEndlessMode(count, BUFF/DEBUFF, ENDLESS_FOR_ROUND_END) mỗi round; GetPositiveAnomaly/GetNegativeAnomaly/GetBlessingsForEndlessMode(seed) cho daily/weekly. Cosmo Academy: GetPerksForCosmoAcademyReward(count) khi đủ shard; cosmoPerkDuration PERMANENT giữ cả run (list_PermanentCosmoPerks) hoặc IN_STAGE_ONLY.
