Mô tả

  • Unity Localization package: 29 String Table Collection (UI 497 key, RelicType 221, Achievements 202, Perks 186, TowerDescription 163, LevelMechanics 135, Character 126, NPCDialog 120, MonsterDescription 112, MonsterName 95, GameTutorial 75, Heroic 73, Talents 63, Runes 62, TowerStats 61, GameSettings 59, TowerType 58, PowerGrid 50, InputAction 33, EmberType 32, Quests 29, PlayerStats 28, LoadingTips 25, Rewards 20, Keywords 20, WorldName 18, Fonts 17, GameTips 3, BuffCard 26) × 13 locale: en, de, es, fr, it, ja-JP, ko, pl, pt-BR, ru, zh-Hans, zh-Hant (+ Fonts). Markup màu [C0]–[C9], keyword [FIRE]/[CHILL]…, {0:plural:…}. Studio Đài Loan: chuỗi debug/log tiếng Trung phồn thể; một số key mới còn trống (Witch, BASIC_LV2, W6–W9).
  • Asset Addressables 'localization-asset-tables-<locale>' và string tables load theo locale; shared data map id → key. Code gọi theo (table, key): ví dụ MapNode 'MAPNODE_{0}' table 'UI'; CoinPage 'SELECT_DIFFICULTY_{0}', 'WorldName', 'Character', 'EmberType'; ABaseBuffSettingData.GetLocNameString → 'BuffCardName'. OnLanguageChanged rebuild UI. TextAnimator (Febucci) cho hiệu ứng chữ, Text Animator settings.

Lưu ý

📌 Chưa xác định: Cơ chế tra loc (LocalizationManager API) chỉ suy từ chuỗi tham số
📌 Chưa xác định: Bảng Fonts map font theo locale chưa đọc

Mở khóa & điểm vào

Điểm vào:

  • Setting GAME_LANGUAGE → OnLanguageChanged
  • LocalizationManager.GetLocString(table, key) (suy luận)
  • TMP font theo locale (Fonts table: setofont SDF, YozaiFont SDF…)

Cách hoạt động

  1. Đổi ngôn ngữ: GameSettingData_Language.settingValue → LocalizationSettings.SelectedLocale → EventMgr OnLanguageChanged → mọi UI UpdateNodeName/OnLanguageChanged
Luồng chi tiết theo code

Asset Addressables 'localization-asset-tables-<locale>' và string tables load theo locale; shared data map id → key. Code gọi theo (table, key): ví dụ MapNode 'MAPNODE_{0}' table 'UI'; CoinPage 'SELECT_DIFFICULTY_{0}', 'WorldName', 'Character', 'EmberType'; ABaseBuffSettingData.GetLocNameString → 'BuffCardName'. OnLanguageChanged rebuild UI. TextAnimator (Febucci) cho hiệu ứng chữ, Text Animator settings.
