Mô tả

  • Cây talent vĩnh viễn mua bằng EXP (25 talent, 1–3 cấp, 10–250 EXP/cấp), reset bất cứ lúc nào hoàn EXP. Nhóm: skill (Overcharge 100, Focus Fire 60, Unlock 70), kinh tế (Initial Advantage +10/20/30 vàng, Shop Discount 1/2/3 món, VIP free reroll 45, Loot Scavenging 1/3/5 gem, Equivalent Exchange 5/10/20 %, High Efficiency Upgrade −5/10/15 %), thẻ (Skilled Engineer +1/2, Blueprint Study trần 30/25/20, Flexible Strategy mulligan 45, Gambler's Gambit 1/2/3 token), nguồn lửa (Fire Enhancement +3/5/10 HP, Flame Renewal +1 HP 60, Ember Sparks, Pyre Transmutation 5/10/15 %), khác (Boss Killer crit 5/10/20 %, Exploit Weakness crit 1/3/5 %, Resilient Forging −5/10/15 %, Treasure Expertise +10/20/30 %, Battlefield Healing 25/50 %, Lost and Found 45, Relic Hunter +1/2, Royal Emblem 250).
  • TalentData.Initialize từ TalentSettingData.list_talentSettings (talentType, maxLevel, cost_LV1..3, param_1..3, isPercentage). LearnTalent(type): kiểm tra exp ≥ GetNextLevelExpCost → RequestLearnTalent → PlayerLifetimeData.exp −= cost, list_LearnedTalent, TalentDataEntry.level++; GameplayData.isHaveAnyTalent (achievement NO_TALENT_HEROIC_CLEAR) và isHaveRoyalPassTalent. ResetAllTalents hoàn GetTotalSpentExp. Code truy vấn qua IsTalentLearned(type) + GetTalentParamInt/AsPercentage. Phiên bản mới đổi nội dung → reset và hoàn (TALENT_PAGE_NOTIFICATION_NEW_VERSION_RESET).

Lưu ý

📌 Chưa xác định: Loc có TIME_MANAGEMENT, EXP_GAIN_INCREASE, WORKSHOP_UPGRADE, RECOVERY_IN_SHOP, TEAM_UP, BAN_TOWER_OR_RELIC nhưng TalentSettingData chỉ 25 entry — code GetRoundFullPrepareTime vẫn +30 s theo talent (id ngoài list?)

Mở khóa & điểm vào

Talent page từ title (OPEN_TALENTS) và trong run (LOADING_TIP_19 'learn new talents during your journey'). lockInDemoVersion/lockInEAVersion flags.

Điểm vào:

  • CoinPage.OnClick_Talents → UI_TalentPage_Popup
  • OPEN_TALENTS (eInputAction 37)
  • TALENT_PAGE_LEARN_ALL (debug/achievement TALENT_LEARN_ALL)

Cách hoạt động

  1. Học talent: TalentData.GetNextLevelExpCost(type) → RequestLearnTalent(type, doSave) → OnRequestLearnTalent: exp −= cost; TalentDataEntry.level++ → OnTalentChanged; SaveData; achievement TALENT_LEARN_FIRST/ALL
  2. Reset talent: RequestResetTalent → TalentData.ResetAllTalents; exp += GetTotalSpentExp → list_LearnedTalent.Clear (Quy tắc: Hoàn 100 %)
  3. Talent tác động trong run: GameplayData.InitializeHP (9), GetStartupRerollCount (5); MainGame.Start (24); GetRoundFullPrepareTime (TIME_MANAGEMENT — không trong list); IngameData.IncreateDrawCost (6); ABaseTower.GetUpgradeCost (17); DiscoverRewardHandler (7, 12); ABaseTower.ApplyTowerTalentBuff (4); Map.RollStageReward (isTutorial); MapSceneProcess (22 Royal Library)
Luồng chi tiết theo code

TalentData.Initialize từ TalentSettingData.list_talentSettings (talentType, maxLevel, cost_LV1..3, param_1..3, isPercentage). LearnTalent(type): kiểm tra exp ≥ GetNextLevelExpCost → RequestLearnTalent → PlayerLifetimeData.exp −= cost, list_LearnedTalent, TalentDataEntry.level++; GameplayData.isHaveAnyTalent (achievement NO_TALENT_HEROIC_CLEAR) và isHaveRoyalPassTalent. ResetAllTalents hoàn GetTotalSpentExp. Code truy vấn qua IsTalentLearned(type) + GetTalentParamInt/AsPercentage. Phiên bản mới đổi nội dung → reset và hoàn (TALENT_PAGE_NOTIFICATION_NEW_VERSION_RESET).
