Mô tả

  • Rewired với 18 control scheme (DEFAULT, COINPAGE, MAP_SCENE, MAIN_GAME, TOWER_BUILD_MODE, TETRIS_BUILD_MODE, BUFF_MODE, TOWER_CONTROL, SCRAP_MASTER_MACHINE, BUILD_TOWER_RING, SELECT_BLOCK_CARD, PAUSED, BASIC_UI, UI_JOURNAL, UI_VICTORY, UI_VICTORY_VIEW_MAP, VIEW_RELIC_DETAIL, CINEMATIC) xếp chồng (stack: 'Attempting to end control scheme…'), ~60 eInputAction (di chuyển, tower ring, DRAW_CARD, CAMERA_ZOOM/ROTATE, CONFIRM/CANCEL, ROTATE_BLOCK(_INV), CONTINUOUS_BUILD, PAUSE, TOGGLE_DPS_METER, SKILL_1–3, SWITCH_GAME_SPEED, DISCARD, START_BATTLE, SELL_TOWER, CHANGE_PRIORITY, UPGRADE_RED/BLUE, BUILD_TOWER_1–8, MULLIGAN, OPEN_TALENTS/COMPENDIUM/SETTINGS/BACKPACK/LOADOUT, SKIP_CUTSCENE…). Hỗ trợ chuột+phím, tay cầm (hàng chục controller map: Xbox, DualShock, Switch, Logitech…), Steam Deck, edge scroll.
  • Mỗi scene/popup push control scheme; InputController phát eInputAction → hệ thống nghe (ObjectPlacementHandler, CardController, UI). Obj_GridInputControl: joystick di chuyển ô (OnGridInputControlCellChanged). Tay cầm: Func_HideWhenUsingController, UI navigation (RebuildNavigationAndSelect), vibration (JOYSTICK_VIBRATION). Keybind remap: InputAction loc table (33 key), ControllerActionTipData gợi ý.

Mở khóa & điểm vào

Điểm vào:

  • InputController.ClearAllAndForceControlScheme(scheme)
  • KeybindManager.RegisterKeybind(name, entry) / IKeybindRegister.OnTriggerKeybind
  • OnInputSourceChanged(ControllerType) đổi glyph (ControllerElementGlyphSelectorOptionsSO)

Cách hoạt động

  1. Đổi control scheme: Push scheme; OnControlSchemeChanged → Đóng → pop; lỗi nếu không phải đỉnh stack (log '嘗試結束control scheme {0}…')
  2. Xây liên tục / đặt nhiều: OnConfirmPlacement(doContinuousBuild) giữ placement → builtTowerWithoutHoldingShiftCount → gợi ý Shift (MiscRecord.PlayerLearnedHoldShiftToBuild)
