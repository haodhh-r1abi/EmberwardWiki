Mô tả

  • Lưu bằng Easy Save 3 (ES3, mã hoá key 'Reficlac'): file SaveData/SaveFile_Slot{n}.sav (3 slot, key PlayerPrefs 'SelectedSaveSlot'), keys: gameVersion, playerdata (PlayerLifetimeData), gameplayData (run hiện tại), intermediateData (stage đang vào). Backup tự động (.sav.bac, _Backup_yyyyMMdd_HHmmss.sav, SaveFile_Prev.sav), lỗi đọc → UI_ShowSaveFileError_UseBackup. Lưu ở cuối frame (doSaveAtEndOfFrame), giới hạn tần suất (saveMinimumTimeLimit), OnApplicationQuit, chuyển slot, sau mỗi node/talent. Temp session (gameplayData_tempSession) cho endless/custom không ghi đè run chính. Screenshot .sc lưu qua ES3.SaveRaw (leaderboard/run record).
  • Initialize → CreateSaveSettings (ES3Settings, password 'Reficlac', cache) → LoadData → CR_LoadDataProc → LoadDataFromSaveFile(path, createIfNotExist): ES3.CacheFile → ES3.Load 'playerdata'/'gameplayData'/'intermediateData'/'gameVersion' → CheckIsSaveFileValid(oldVersion) → 'Processing Version Differences' (migrate: MigrateRemovedTower, ClearEvents/RegisterEvents, '存檔使用不可使用的火焰 → 強制改成基本' ép ember về BASIC nếu không hợp lệ). Save: ES3.CreateBackup nếu file tồn tại → ghi 4 key vào cache → ES3.StoreCachedFile. SwitchSaveSlot(slot): Save slot cũ, đổi SelectedSaveSlot, load slot mới; CreateNewSaveSlotData. DeleteSaveData xoá .sav/.bac/_Backup/Demo. Media preview: copy TextAsset bundled vào slot 2/3 nếu trống (build preview).

Lưu ý

📌 Chưa xác định: saveMinimumTimeLimit giá trị chưa đọc
📌 Chưa xác định: Cấu trúc ES3Types (ES3Types namespace 1962 method) cho từng class — đọc trực tiếp file .sav cần password trên

Mở khóa & điểm vào

Điểm vào:

  • CoinPage → UI_SelectSaveSlot_Popup (SAVE_SLOT_*)
  • Setting RESET_GAME (ForceResetData) / LOAD_FROM_ACHIEVEMENT
  • GameDataManager.SaveData(forceImmediate)

Cách hoạt động

  1. Chọn / đổi slot: SlotPreviewData: hasSaveData, gameVersion, playerLifetimeData, gameplayData (SAVE_SLOT_CHARACTER/TALENTS/BEST_PROGRESS/CURRENT_GAME) → SwitchSaveSlot(n): Save hiện tại, PlayerPrefs SelectedSaveSlot, LoadData → Slot trống → CreateNewSaveSlotData (Quy tắc: SAVE_SLOT_COUNT 3)
  2. Lưu tự động: SaveData(force) → doSaveAtEndOfFrame → LateUpdate: Save() → ES3.CreateBackup(file) → cache → StoreCachedFile → isShownSaveError nếu lỗi (Quy tắc: Tiến độ trong stage không lưu (BACK_TO_TITLE_CONFIRM_INGAME))
  3. Khôi phục khi hỏng: '找不到ES3存檔' / exception → UI_ShowSaveFileError_UseBackup → Dùng .sav.bac / _Backup_*.sav / SaveFile_Prev.sav → Hoặc LOAD_FROM_ACHIEVEMENT tái tạo từ Steam achievement
  4. Reset toàn bộ: ForceResetData: ES3.DeleteFile các file → LoadData tạo mới → ResetTutorialState / ResetBossLevelTutorialState riêng
Luồng chi tiết theo code

Initialize → CreateSaveSettings (ES3Settings, password 'Reficlac', cache) → LoadData → CR_LoadDataProc → LoadDataFromSaveFile(path, createIfNotExist): ES3.CacheFile → ES3.Load 'playerdata'/'gameplayData'/'intermediateData'/'gameVersion' → CheckIsSaveFileValid(oldVersion) → 'Processing Version Differences' (migrate: MigrateRemovedTower, ClearEvents/RegisterEvents, '存檔使用不可使用的火焰 → 強制改成基本' ép ember về BASIC nếu không hợp lệ). Save: ES3.CreateBackup nếu file tồn tại → ghi 4 key vào cache → ES3.StoreCachedFile. SwitchSaveSlot(slot): Save slot cũ, đổi SelectedSaveSlot, load slot mới; CreateNewSaveSlotData. DeleteSaveData xoá .sav/.bac/_Backup/Demo. Media preview: copy TextAsset bundled vào slot 2/3 nếu trống (build preview).
