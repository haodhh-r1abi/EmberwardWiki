Mô tả

  • Mỗi node battle chọn một EnvScene (bố cục sân + portal + mechanic) theo world và stageLevel 1–3, gắn StageSettingData (list_WaveData: 5–10 wave, phổ biến 8; mỗi wave difficultyMultiplier cộng dồn và danh sách spawn). 122 StageSettingData (StageData_001…420, Data_Boss01–05, Workshop, 901–910 event). Có thể thêm wave (endless, Victory Challenge) và ghi đè quái (MonsterSpawnOverrideData).
  • GetRandomScene(world, stageLevel) tránh scene đã chơi (list_PlayedEnvScene). Vào màn: LoadStageData(stageData clone). Mỗi round: BeforeNextWaveStartProcess (áp MonsterSubstitude, override), GetNextWaveMonsterInfo cho UI; StartNextWave → CR_WaveProc → với mỗi MonsterSpawnData chạy CR_MonsterWaveProc: đợi startTime, spawn countForEachSpawn quái mỗi interval, waveCount lần; wave xong khi hết quái (noMonsterOnFieldTimer) hoặc ForceTerminateBattle. HasNextWave false → stage thắng. AddExtraWaveAtEnd_AutoGenerate / _FromEndlessWaveSetting nối wave mới (EndlessExtraWaveSettingData theo world, diffMult 0.35).

Lưu ý

📌 Chưa xác định: Bố cục lưới/portal của từng EnvScene nằm trong scene Unity, chưa trích
📌 Chưa xác định: Cách chọn stageLevel theo bước (1/2/3) suy từ dữ liệu, chưa đọc code CR_BattleNodeProc đầy đủ

Mở khóa & điểm vào

EnvSceneCollectionData: enableInRandomPick=1 mới được chọn ngẫu nhiên; canHavePathLengthQuest; scene event 9xx chỉ qua endless/event.

Điểm vào:

  • MapSceneProcess.CR_BattleNodeProc → EnvSceneCollectionData.GetRandomScene
  • MainGame.Awake → sceneEntry; StageDataReader.LoadStageData

Cách hoạt động

  1. Chọn scene cho node: stageLevel theo bước: 1 (đầu), 2, 3 (cuối/hard) → GetRandomScene(worldType, level) trong sceneEntries enableInRandomPick → GameplayData.RecordPlayedScene tránh lặp → Corrupted/Anomaly/Darkness: cùng scene, thêm perk/corrupted grid (Quy tắc: W1 26 scene, W2 19, W3 18, W4 19, W5 19 (+boss 099/199/299/399/498/499))
  2. Chạy wave: StartNextWave(callback) → CR_WaveProc(waveData) → Mỗi MonsterSpawnData: CR_MonsterWaveProc(data, treasureCount) → OnWaveIndexChanged; WAVEANNOUNCE '- WAVE {0} -' / FINAL WAVE → Hết quái → OnBattleEnd → OnRoundEnd (Quy tắc: Ví dụ StageData_001: 8 wave; Data_Boss01: 6 wave diffMult 0/0.15/0.15/0.15/0.2/0.2, 211 quái)
  3. Thêm wave sau khi thắng (Victory Challenge / after-boss endless): RequestStartVictoryChallengeMode → IngameData.IsVictoryChallengeModeActivated → AddExtraWaveAtEnd_AutoGenerate(diffMult) hoặc FromEndlessWaveSetting → GetCurrentAfterBossChallengeMultiplier = (levelClearedAfterBoss+1)×0.15 tăng dần theo round → Dừng khi quái chạm nguồn lửa; không thưởng (VICTORY_CHALLENGE_DESCRIPTION) (Quy tắc: VICTORY_CHALLENGE_WAVE_D
  4. Ngày/đêm và môi trường: EnvSceneSettingData: gradient ánh sáng theo thời gian, curve intensity, FirstDay/FastForward → eSceneTimeType DAYTIME/NIGHT; RoundTimeFastForwardToNight → 22 preset: Forest/Desert/Mountain/Ruins/Cosmo Day/Night, Boss, Graveyard, Christmas, Garden, Sanctum, Workshop
Luồng chi tiết theo code

GetRandomScene(world, stageLevel) tránh scene đã chơi (list_PlayedEnvScene). Vào màn: LoadStageData(stageData clone). Mỗi round: BeforeNextWaveStartProcess (áp MonsterSubstitude, override), GetNextWaveMonsterInfo cho UI; StartNextWave → CR_WaveProc → với mỗi MonsterSpawnData chạy CR_MonsterWaveProc: đợi startTime, spawn countForEachSpawn quái mỗi interval, waveCount lần; wave xong khi hết quái (noMonsterOnFieldTimer) hoặc ForceTerminateBattle. HasNextWave false → stage thắng. AddExtraWaveAtEnd_AutoGenerate / _FromEndlessWaveSetting nối wave mới (EndlessExtraWaveSettingData theo world, diffMult 0.35).
