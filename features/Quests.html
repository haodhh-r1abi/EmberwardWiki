Mô tả

  • 23 loại quest (eQuestType) thực hiện trong 1 stage: không mất máu, giữ quái cách nguồn lửa ≥3/5 ô, không dùng tháp X/Y, không xây tháp/khối trong battle, ≤3 loại tháp, tháp không kề nhau, rút ≥15 thẻ, Dice tower ra 6 ×3, không bán tháp, gây {0} dmg hệ, xây ≥{0} tháp 2x2/loại cụ thể, nâng cấp {0} tháp đỏ/xanh, đường ≥{0} ô. Độ khó EASY/NORMAL/HARD; thưởng eQuestRewardType GEM/EXP/TOWER/TETRIS/RELIC/REROLL (gem/exp ×5 multiplier). Nguồn: node QUEST (weight 0 — tắt), relic Royal Command (Knight): quest mỗi stage +10 gem +10 EXP.
  • QuestManager.GetRandomQuestData(difficulty, excludeType): lọc list_ChallengeData isInGame, difficultyXAvailable, requirement (PlayerMinTowerCount, PlayerHasTower, PlayerHasTowerType, PlayerHasTowerSize(WithCount)); RequestAddQuest(QuestData) → GameplayData.quest; vào stage OnRequestLoadQuestInGame tạo AQuestBase con (Quest_NoSellTower, Quest_LockOneRandomTower…) theo dõi event; eQuestStatus IN_PROGRESS → SUCCESS/FAILED (OnQuestSuccess/Failed/BackToInProgress, UpdateQuestUIProgressText). Cuối stage IsQuestSuccess → thưởng QuestRewardEntry; PlayerRecord.questCompleted (achievement COMPLETE_QUEST_MORE_THAN_X).

Lưu ý

📌 Chưa xác định: Giá trị {0} của quest damage/build (Requirement_value_*) phần lớn 0 trong SO → tính động trong Quest_* class
📌 Chưa xác định: QuestRewardEntry cụ thể mỗi quest không nằm trong SO

Mở khóa & điểm vào

Royal Command (4001) hoặc node QUEST; requirement theo loadout (PlayerHasTower/Type/Size/MinTowerCount).

Điểm vào:

  • UI_MapScene_Quest_Popup / UI_Obj_QuestBoard (chọn)
  • UI_QuestAnnounce_Popup đầu stage
  • UI_QuestStatus HUD; UI_QuestReward_Popup

Cách hoạt động

  1. Nhận quest từ Royal Command: GetRandomQuestData theo độ khó → RequestAddQuest; UI_QuestAnnounce_Popup → Xong → +10 Ember Stone +10 EXP
  2. Theo dõi và kết thúc quest: Quest_* lắng nghe (OnTowerSold, OnMonsterDealDamage, OnTowerPlaced…) → Vi phạm → OnQuestFailed (có thể BackToInProgress) → Thắng stage → IsQuestSuccess → UI_QuestReward_Popup (Quy tắc: Quest 20 (maze length) cần scene canHavePathLengthQuest)
Luồng chi tiết theo code

QuestManager.GetRandomQuestData(difficulty, excludeType): lọc list_ChallengeData isInGame, difficultyXAvailable, requirement (PlayerMinTowerCount, PlayerHasTower, PlayerHasTowerType, PlayerHasTowerSize(WithCount)); RequestAddQuest(QuestData) → GameplayData.quest; vào stage OnRequestLoadQuestInGame tạo AQuestBase con (Quest_NoSellTower, Quest_LockOneRandomTower…) theo dõi event; eQuestStatus IN_PROGRESS → SUCCESS/FAILED (OnQuestSuccess/Failed/BackToInProgress, UpdateQuestUIProgressText). Cuối stage IsQuestSuccess → thưởng QuestRewardEntry; PlayerRecord.questCompleted (achievement COMPLETE_QUEST_MORE_THAN_X).
