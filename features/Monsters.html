Mô tả

  • 95 MonsterSettingData (eMonsterType 1–89, boss 101–105, dummy 900): 3 cỡ SMALL/MEDIUM/LARGE + BOSS, đường GROUND/AIR, HP gốc 2–379 (quái thường) nhân theo độ khó và Inferno Shard, tốc độ min–max ngẫu nhiên, reward vàng 0–50. Quái lớn có kỹ năng riêng (class MonsterScript_*), quái NPC (Ancient tower, crystal) là 'monster' bất động HP cố định. Quái đi theo FloodPath từ portal (MonsterSpawner) tới nguồn lửa; đổi đường khi khối đặt.
  • Spawn(type, hasTreasure, isCorrupted): MonsterManager.SpawnMonster tạo từ prefab, AMonsterBase.Spawn: maxHP = MonsterSettingData.GetMaxHP(multiplier) = baseHP × (1 + độ khó hiện tại) × (1 + HardMode HP%/100) (isHPScalable) ; corrupted ×1.2; speed = GetMoveSpeed = Random(min,max); electricEffectMax theo size; aiPath.maxSpeed. Di chuyển theo FloodPathTracer; RecalculatePath khi OnFloodPathUpdated; Unstuck nếu kẹt. Tới đích: ReachEndOfPathProc → MonsterDealDamageToPlayer → Despawn. Chết: DeathProc, GetReward vàng (×0 nếu Skeleton 15/crystal), doDropChestOnDeath → Obj_Chest, OnMonsterKilled_Global (relic, achievement ELITE/BOSS_KILLED).

Lưu ý

📌 Chưa xác định: Kỹ năng từng quái lớn (MonsterScript_*) chưa đọc số
📌 Chưa xác định: Công thức chính xác (1+difficulty) trong GetMaxHP là suy luận từ multiplier truyền vào
📌 Chưa xác định: Tỉ lệ quái mang rương (GetTreasureCountInThisRound) chưa đọc

Mở khóa & điểm vào

Theo world (avaliableWorldType bitmask, mainWorldType); MonsterSubstitudeSettingData thay thế quái lớn bằng quái vùng khác (Shard Environment L2).

Điểm vào:

  • StageDataReader.CR_MonsterWaveProc → MonsterSpawner.Spawn
  • Boss/perk/relic gọi RequestSpawnMonster (skeleton on kill, Void Army, Slime Army)

Cách hoạt động

  1. Spawn theo wave: WaveData.list_SpawnData: type, spawnNodeIndex (portal), startTime, spawnIntervalMultiplier, waveCount, countForEachSpawn → WaveData.CalculateInterval: base 1.0 (SMALL) / 2.5 (MEDIUM) / 5.0 (LARGE) / 11.0 (BOSS) × spawnIntervalMultiplier × monster.spawnIntervalModifier → GetTreasureCountInThisRound → một số quái mang rương (talent Treasure Expertise +10/20/30 %) → MonsterSpawner.Spawn(type, isHaveTrea
  2. Tìm đường và đổi đường: MonsterSpawner.CalculateFloodPath(target) → FloodPath; SetupPathLine vẽ đường (mat_PathLine_Incoming) → AMonsterBase.RecalculatePath → GetFloodPathTracer; OnPathReady → Portal (Obj_PathPortal) là NodeLink2 — quái có thể dùng làm lối tắt (PORTAL_DESC) → Wind zone: nhanh/chậm theo hướng; slime block −20 % (Quy tắc: Void Army/Voidwing bay thẳng (AIR, không bị mê cung); Phantom xuyên khối)
  3. Quái lớn dùng kỹ năng: Ví dụ Werebeast (2): dưới 50 % HP đập đất; Necromancer (14) triệu Skeleton (15); Orc Warchief; Salamander Mage; Builder Bot; Commander Bot buff → InterruptSkill khi stun; Shard Monster L3 tăng tần suất (Quy tắc: Mô tả từng quái trong appendix/monsters.md (MonsterDescription loc))
  4. Rương và vàng khi chết: GetReward → RequestAddCoin (×1.5 Gold tile, ×2 DoubleCoin buff) → doDropChestOnDeath → Obj_Chest (mở khi tay chưa đầy: CHEST_HAND_FULL) → DiscoverRewardHandler → Shard Corrupt L1: 5/15/25 % tạo Corrupted tile theo size; anomaly SPAWN_SKELETON_ON_KILL → PlayerRecord.AddEnemiesKilled/AddEliteKills/AddBossKills (Quy tắc: Chest drop rate −50 % Shard Gold L1)
  5. Quái NPC/persistent: Ancient Fireball/Sniper/Defense/Thunder/Freeze Tower (51–55) HP 200–2400, dmg 0, tấn công tháp gây malfunction → Frozen Treasure (58) HP 1000, Obstacle (59) 250, Void/Energy Crystal (74–76, 85) HP cố định 350–3480, Lightning/Frost/Magma Core (87–89) 3500 → destroyPersistentMonsterOnDespawn
Luồng chi tiết theo code

Spawn(type, hasTreasure, isCorrupted): MonsterManager.SpawnMonster tạo từ prefab, AMonsterBase.Spawn: maxHP = MonsterSettingData.GetMaxHP(multiplier) = baseHP × (1 + độ khó hiện tại) × (1 + HardMode HP%/100) (isHPScalable) ; corrupted ×1.2; speed = GetMoveSpeed = Random(min,max); electricEffectMax theo size; aiPath.maxSpeed. Di chuyển theo FloodPathTracer; RecalculatePath khi OnFloodPathUpdated; Unstuck nếu kẹt. Tới đích: ReachEndOfPathProc → MonsterDealDamageToPlayer → Despawn. Chết: DeathProc, GetReward vàng (×0 nếu Skeleton 15/crystal), doDropChestOnDeath → Obj_Chest, OnMonsterKilled_Global (relic, achievement ELITE/BOSS_KILLED).
