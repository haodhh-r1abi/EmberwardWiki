Mô tả

  • 'Sacred domain built within the academy — endless simulations to find the perfect strategy': chế độ endless trên lưới mê cung 7×7 dựng sẵn (SanctumOfEnigmaMazeData.mazeLayouts: list_BlockState mỗi ô eMazeBlockState Default/Up_1..3/Down_1..3/Mechanic_A/B/C/Platform), wave lặp vô hạn (SanctumOfEnigmaMonsterWaveData: nhóm wave theo world với waveCount 999999, diffMult 0.1), thưởng round chủ yếu SCENE_RESET ở round 3/6 (EndlessModeWaveRewardData_SanctumOfEnigma). Có DAILY/WEEKLY/CASUAL với leaderboard riêng.
  • Chọn daily/weekly/casual (eEndlessModeType 5–7) → seed cố định (daily/weekly) → StageScript_SanctumOfEnigma dựng mê cung từ mazeLayouts (2 asset, mỗi asset nhiều layout 7×7), ô Selectable/Activated (DungeonCellData) → người chơi mở rộng theo cell; wave từ SanctumOfEnigmaMonsterWaveData luân phiên nhóm quái (16/1/2; 6/7/5/28; 15/13/32; 47/36; 49/38/48…); SCENE_RESET đổi layout; điểm lên eLeaderboardType DAILY/WEEKLY_CHALLENGE_ENIGMA_SANCTUM.

Mở khóa & điểm vào

IsEnigmaSanctumUnlocked = clear Sealed Citadel bất kỳ độ khó; ENIGMA_SANCTUM_FINISH achievement.

Điểm vào:

  • Endless select: SELECT_DIFFICULTY_EVENT_SANCTUM_OF_ENIGMA
  • EnvScene_907 (SANCTUM_1 music)

Cách hoạt động

  1. Chơi Sanctum: Chọn Daily/Weekly/Casual → Layout 7×7 từ mazeLayouts; cell state → Wave lặp; round 3/6 SCENE_RESET → Thua → leaderboard
Luồng chi tiết theo code

Chọn daily/weekly/casual (eEndlessModeType 5–7) → seed cố định (daily/weekly) → StageScript_SanctumOfEnigma dựng mê cung từ mazeLayouts (2 asset, mỗi asset nhiều layout 7×7), ô Selectable/Activated (DungeonCellData) → người chơi mở rộng theo cell; wave từ SanctumOfEnigmaMonsterWaveData luân phiên nhóm quái (16/1/2; 6/7/5/28; 15/13/32; 47/36; 49/38/48…); SCENE_RESET đổi layout; điểm lên eLeaderboardType DAILY/WEEKLY_CHALLENGE_ENIGMA_SANCTUM.
