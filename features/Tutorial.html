Mô tả

  • 38 tutorial (eTutorialType) hiện popup 1 lần theo sự kiện (dic_EventToTutorial: eGameEvents → tutorial) hoặc xếp hàng đầu stage (QueueTutorialForGameStart); màn tutorial riêng (StageScript_Tutorial, EnvScene_000, Training Dummy 900) trước run đầu; list_FinishedTutorial trong save; 27 tutorial hiện trong journal (isShowInJournal) kèm ảnh. Ngoài ra 25 Loading Tips, 3 Game Tips, Controller action tips.
  • TutorialManager.Update chờ event; CR_TutorialProc(type, delay, cb): kiểm tra IsFinishedTutorial → mở UI_ItemTutorialPopup (sprite từ TutorialSettingData, text GameTutorial/{KEY}, _DESC) → OnFinishedTutorial → PlayerLifetimeData.list_FinishedTutorial; RequestSetTutorialFinished. Màn tutorial: isTutorialStageFinished → cho phép node đặc biệt (RollMapNodeType step<5 chỉ battle khi chưa xong).

Lưu ý

📌 Chưa xác định: Bảng dic_EventToTutorial (event nào → tutorial nào) nằm trong prefab TutorialManager

Mở khóa & điểm vào

Lần đầu gặp cơ chế; ResetTutorialState / ResetBossLevelTutorialState (setting).

Điểm vào:

  • RequestTutorial(type, delay, callback)
  • QueueTutorialForEvent(eGameEvents, type) / QueueTutorialForGameStart(type) → RequestStartQueuedTutorial
  • Journal tab tutorial

Cách hoạt động

  1. Màn huấn luyện: StageScript_Tutorial: BUILD_TETRIS → BUILD_TOWER → BASIC_STAGE → BUFF_CARD; Training Dummy HP 3600 → RequestSetTutorialStageCompleted; achievement ADVENTURE_BEGIN
  2. Tutorial theo cơ chế: dic_EventToTutorial map; CR_PlayQueuedTutorial → Popup ảnh + text; SKIP_CUTSCENE
Luồng chi tiết theo code

TutorialManager.Update chờ event; CR_TutorialProc(type, delay, cb): kiểm tra IsFinishedTutorial → mở UI_ItemTutorialPopup (sprite từ TutorialSettingData, text GameTutorial/{KEY}, _DESC) → OnFinishedTutorial → PlayerLifetimeData.list_FinishedTutorial; RequestSetTutorialFinished. Màn tutorial: isTutorialStageFinished → cho phép node đặc biệt (RollMapNodeType step<5 chỉ battle khi chưa xong).
