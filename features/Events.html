Mô tả

  • Các chế độ endless theo mùa dùng scene 9xx và bảng thưởng riêng: Misty Graveyard (Halloween 2024, EnvScene_901, Ghost Flame: quái +150 % HP nhưng mất 1 %/s; thưởng SKELETON_KING_TRIAL xen kẽ), Snowridge Outpost (Xmas 2025, EnvScene_908, XMAS_GIFT mỗi round), Wyrmfell Bridge (TD Fest 2026, EnvScene_910, 'tài nguyên hạn chế, phòng thủ kiểu truyền thống' — StageScript_LineTowerDefense với 5 tháp cố định 1065/1026/1033/1013/1028), Royal Garden (EnvScene_909, GARDEN_1). Mỗi event có leaderboard riêng (EVENT_HALLOWEEN_2024 v1–v3, EVENT_XMAS_2025, EVENT_TD_FEST_2026). Hiện isActivated=0 (tắt trong build này).
  • Như Endless nhưng StageScript riêng: HalloweenEvent (tutorial HALLOWEEN_EVENT: 'dùng thưởng trong trận để tăng phòng thủ'), Xmas (nhận quà từ adventurer khác — XMAS_GIFT reward type 12), LineTowerDefense (TD Fest: hàng tháp cố định, EndlessModeWaveRewardData_TDFestEvent chỉ NONE + repeat). Achievement MISTY_GRAVEYARD_WAVE_20, XMAS_EVENT_WAVE_20, TD_EVENT_WAVE_20.

Lưu ý

📌 Chưa xác định: Nguồn 'server time' (OnTimeReady) — Steam hay HTTP — chưa xác định
📌 Chưa xác định: Royal Garden (StageScript_RoyalGarden, EnvScene_909) không có endless entry → có thể chưa ship

Mở khóa & điểm vào

Halloween/daily: clear Sealed Citadel bất kỳ độ khó (SELECT_DIFFICULTY_EVENT_HALLOWEEN_UNLOCK, DAILY_CHALLENGE_LIMIT).

Điểm vào:

  • CoinPage endless select (khi active theo thời gian server OnTimeReady)
  • CR_StartEndlessMode(type=HALLOWEEN_EVENT/XMAS_EVENT/TD_FEST_EVENT)

Cách hoạt động

  1. Misty Graveyard: EnvScene_901 (GHOST_1 music), StageData_901 → Ghost Flame ability → Thưởng: TOWER/RELIC + TREASURE/REROLL/SKELETON_KING_TRIAL (EndlessModeWaveRewardData_HalloweenEvent)
  2. Snowridge Outpost (Xmas): EnvScene_908 CHRISTMAS_1; EnvSceneSetting_Christmas → Mỗi round XMAS_GIFT (+TOWER/RELIC/TREASURE)
  3. Wyrmfell Bridge (TD Fest): StageScript_LineTowerDefense: loadout cố định TowerIngameData 0x429 Fort, 0x402 Hammer, 0x409 Lasso, 0x3f5 Fireball, 0x404 Piranha (level 1) → Không thưởng round (TDFest reward NONE)
Luồng chi tiết theo code

Như Endless nhưng StageScript riêng: HalloweenEvent (tutorial HALLOWEEN_EVENT: 'dùng thưởng trong trận để tăng phòng thủ'), Xmas (nhận quà từ adventurer khác — XMAS_GIFT reward type 12), LineTowerDefense (TD Fest: hàng tháp cố định, EndlessModeWaveRewardData_TDFestEvent chỉ NONE + repeat). Achievement MISTY_GRAVEYARD_WAVE_20, XMAS_EVENT_WAVE_20, TD_EVENT_WAVE_20.
