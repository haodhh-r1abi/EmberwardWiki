Mô tả

  • Bảng xếp hạng Steam cho Daily/Weekly Endless, Daily/Weekly Enigma Sanctum và event (Halloween 2024 v1–3, Xmas 2025, TD Fest 2026). Tên bảng = tên loại + extraName (map) + version app (GetFullLeaderboardName '{0}' + '_' + extra); upload score kèm extraParams (int[]) và ảnh chụp màn hình (leaderboard_shot.png qua Steam Remote Storage UGC, AttachLeaderboardUGC); tải top range + entry người chơi + avatar (AvatarImageLoaded) + ảnh UGC.
  • UploadLeaderboard(type/name, extraName, mainValue, screenshot, extraParams) → CR UploadLeaderboard_Steam: FindOrCreateLeaderboard(fullName) → OnLeaderboardFindResult → UploadLeaderboardScore(KeepBest) → OnLeaderboardScoreUploaded ('新分數: {0}，分數是否變更: {1}') → TryUploadScreenshotAndAttach (FileWrite leaderboard_shot.jpg/png → FileShare → AttachLeaderboardUGC). Download: DownloadLeaderboard(uiId, type, extraName, rangeStart, rangeEnd, extraParamCount, callbacks) → FindLeaderboard → DownloadLeaderboardEntries (Global range + GlobalAroundUser) → OnLeaderboardScoresDownloaded → entries + GetPlayerAvatar + DownloadUGC. CalculateEntryWeightedScore(entry) trả TotalKill (hoặc 0) cho sắp xếp phụ. Status enum eLeaderBoardUploadStatus / eLeaderboardDownloadStatus.

Lưu ý

📌 Chưa xác định: Chuỗi literal định dạng tên bảng (_StringLiteral_2499/16420) chưa tra text
📌 Chưa xác định: extraParams gồm gì (kill, wave, character?) chưa đọc

Mở khóa & điểm vào

Cần Steam online (SteamManager.Initialized); lỗi → LEADERBOARD_ERROR.

Điểm vào:

  • Kết thúc endless/event → UploadLeaderboard
  • UI leaderboard trong endless select (LEADERBOARD_TITLE / _OLD)
  • eInputAction? (không có) — UI_DirectLeaderboard_Popup

Cách hoạt động

  1. Upload điểm: GetFullLeaderboardName(type, extra, includeVersion=true) → FindOrCreateLeaderboard; UploadLeaderboardScore(score, extraParams) → Screenshot: pendingScreenshotTexture → FileWrite → AttachLeaderboardUGC → UI kết quả rank (Quy tắc: Score giữ tốt nhất (KeepBest, suy luận))
  2. Xem bảng: DownloadLeaderboard(range, extraParamCount) → Entries + user entry ('玩家目前排名: {0} - 分數: {1}'); avatar; UGC screenshot khi click (UI_LeaderboardScreenshot_Popup) → LEADERBOARD_TITLE_OLD cho kỳ trước
Luồng chi tiết theo code

CalculateEntryWeightedScore(entry) trả TotalKill (hoặc 0) cho sắp xếp phụ. Status enum eLeaderBoardUploadStatus / eLeaderboardDownloadStatus.
