Mô tả

  • Custom Game (eExtraRewardType CUSTOM_GAME): run roguelite 'bí mật' không ghi record/achievement/EXP, bắt đầu ở Secret Vault chọn tối đa 8 tháp + relic từ mọi thứ đã dùng (list_UnlockedRelics, list_BuiltTowerRecord). Quick Play (eGameMode QUICKPLAY): vào thẳng một scene với nhân vật/ember/tháp/khối chỉ định (CR_StartQuickPlay — dùng cho debug/tutorial/event). Victory Challenge: sau khi thắng stage thường, chơi tiếp wave khó dần (HP+/Speed+/Gold−) không thưởng; after-boss Endless: tiếp tục run sau boss với độ khó +15 %/level, không EXP.
  • Custom: GameplayData.isCustomGame=true → PlayerRecord.IsCustomGame chặn record; AnalyticsManager? vẫn gửi. Map node 0 = SECRET_VAULT → UI_MapScene_SecretVault_Popup chọn ≤8 tháp (CUSTOM_RUN_CHOOSE_TOWER_TITLE) + relic → loadout. Victory Challenge: RequestStartVictoryChallengeMode → IngameData.IsVictoryChallengeModeActivated, VictoryChallengeWaveCount; wave tự sinh (AddExtraWaveAtEnd_AutoGenerate) đến khi quái chạm lửa → IsVictoryChallengeModeFinished. After-boss: GameplayData.SetStartAfterBossChallengeMode(true), levelClearedInAfterBossEndlessMode, GetMaxAfterBossChallengeMultiplier = (level+1)×0.15.

Lưu ý

📌 Chưa xác định: SCORE_ATTACK / STAY_ALIVE_TIME mission có enum + CR_GameEndProc_ScoreAttack nhưng chưa thấy entry UI
📌 Chưa xác định: Quick Play chỉ thấy qua CoinPage.CR_StartQuickPlay (tham số scene/character/towers) — có thể là debug

Mở khóa & điểm vào

Custom: IsRogueliteModeCustomGameUnlocked(difficulty) = clear W5 ở độ khó đó. Victory Challenge: mọi stage. After-boss endless: sau thắng boss.

Điểm vào:

  • CoinPage → UI_CustomGameSelect_Popup (CUSTOM_RUN_*)
  • Node SECRET_VAULT (19) thay ACADEMY
  • UI_VictoryChallengeConfirm_Popup sau thắng; VICTORY_ENDLESS sau boss

Cách hoạt động

  1. Custom Game: Chọn world/độ khó/nhân vật → Secret Vault: ≤8 tháp, relic tuỳ ý → Run bình thường; không record/achievement/EXP (CUSTOM_RUN_DESC_SHORT)
  2. Victory Challenge: UI_VictoryChallengeConfirm_Popup (VICTORY_CHALLENGE_DESCRIPTION) → RequestStartVictoryChallengeMode → wave tiếp (HP+{0}% Speed+{1}% Gold−{2}%) → Quái chạm lửa → kết thúc, không mất máu thật (suy luận) (Quy tắc: Không thưởng thêm)
  3. After-boss Endless: VICTORY_ENDLESS_DESCRIPTION: không EXP, độ khó tăng → SetStartAfterBossChallengeMode(true); mỗi stage clear AddAfterBossChallengeModeWinCount → GetCurrentDifficulty × (1 + (level+1)×0.15 theo round)
Luồng chi tiết theo code

Custom: GameplayData.isCustomGame=true → PlayerRecord.IsCustomGame chặn record; AnalyticsManager? vẫn gửi. Map node 0 = SECRET_VAULT → UI_MapScene_SecretVault_Popup chọn ≤8 tháp (CUSTOM_RUN_CHOOSE_TOWER_TITLE) + relic → loadout. Victory Challenge: RequestStartVictoryChallengeMode → IngameData.IsVictoryChallengeModeActivated, VictoryChallengeWaveCount; wave tự sinh (AddExtraWaveAtEnd_AutoGenerate) đến khi quái chạm lửa → IsVictoryChallengeModeFinished. After-boss: GameplayData.SetStartAfterBossChallengeMode(true), levelClearedInAfterBossEndlessMode, GetMaxAfterBossChallengeMultiplier = (level+1)×0.15.
