Mô tả

  • Tiến trình vĩnh viễn ngoài talent: world (clear world trước), ember, nhân vật, Heroic (boss Normal), Anomaly stage (clear W3), Endless (clear W1), Enigma Sanctum (clear W4), Halloween/daily (clear W4), Inferno Shard + Custom Game + Academy reroll vô hạn (clear W5), Chaos Realm (clear W5), block skin (mua Ember Stone? unlockCost 300–3750), background title (IsCoinpageBackgroundUnlocked). Compendium (journal) ghi tháp đã thấy/xây, relic đã mở/thấy, quái, tutorial; Records: PlayerRecord (39 counter), StageRecord theo độ khó/world/index, RunRecord (lịch sử run: nhân vật, ember, world, shard, thời gian, damage theo hệ, tháp/relic/stage).
  • Sau mỗi run/stage: StageRecord.RecordStageEnd(difficulty, world, stageType, index, isWin) (index 99 = boss); PlayerLifetimeData.IsWorldCleared(d, w) = win>0 ở index 99; IsWorldUnlocked(d, w): W1 luôn; W2 cần W1 cleared ở difficulty ≥ d …; RunRecord.AddRunRecord(RunRecordData). Compendium: RequestRecordSeenTowerCard/RecordTowerBuilt/RecordSeenRelic; JOURNAL_BUILT_TOWER_COUNT/USED_RELIC_COUNT. Block skin: RequestUnlockBlockSkin(type) → list_UnlockedBlockSkins; RequestSetBlockSkin → tetrisSkinType (TAB_BLOCK_SKIN trong customize).

Lưu ý

📌 Chưa xác định: Tiền tệ mua block skin/background chưa xác định từ code (RequestUnlockBlockSkin không trừ gì rõ)
📌 Chưa xác định: Điều kiện từng background (GetCoinpageBackgroundUnlockRequirementText) chưa đọc

Mở khóa & điểm vào

Xem từng mục; UI_NewUnlockPopup (EmberUnlockData, ExtraRewardUnlockData eExtraRewardType: ANOMALY_LEVEL, CHAOS_REALM, INFERNO_SHARD_LV1–3, ENDLESS_MODE, CUSTOM_GAME, ENIGMA_SANCTUM) thông báo 1 lần (list_NotifiedExtraRewards).

Điểm vào:

  • OPEN_COMPENDIUM (eInputAction 38) → UI_ItemJournal_Popup (tower/relic/monster/tutorial/achievement/record)
  • CoinPage → Stats (OnClick_Stats)
  • UI_Journal_RunRecordPage

Cách hoạt động

  1. Mở world kế: StageRecord index 99 win++ → IsWorldUnlocked(difficulty, next): kiểm tra world trước cleared ở difficulty ≥ chọn → MapScene/character select cho phép chọn world (Quy tắc: WORLD_n_UNLOCK loc: 'Unlock after clearing the X')
  2. Compendium: Tab tháp (JOURNAL_TOWER_FILTER_ALL/OTHER; UI_Obj_JournalTowerCard: seen/built count), relic (used count), quái (doShowInJournal, journalSprite), tutorial (isShowInJournal), achievement, record → Scholar unlock: ≥40 tháp trong compendium
  3. Block skin & background: TetrisSkinSettingData: unlockCost (Wood 300… Golden Box 3750, Dice 777); RequestUnlockBlockSkin → CoinPage.SwitchBackground(eBackGroundType); IsCoinpageBackgroundUnlocked + GetCoinpageBackgroundUnlockRequirementText; CUSTOMIZE_RANDOM (Quy tắc: Đơn vị mua skin chưa rõ (Ember Stone chỉ có trong run) — (suy luận: EXP hoặc gem tích luỹ))
  4. Run record: RunRecordData: character, ember, world, difficulty, hardModeSetting, runDurationSeconds, runDateTime, isWin, damageTaken, finalHP/MaxHP, totalGold, damage theo hệ, mostBuiltTower(+count), list_Towers/Relics/ClearedStages, list_TalentLevels → UI_Journal_RunRecordPage; RogueliteCharacterClearRecord/ScoreRecord
Luồng chi tiết theo code

Sau mỗi run/stage: StageRecord.RecordStageEnd(difficulty, world, stageType, index, isWin) (index 99 = boss); PlayerLifetimeData.IsWorldCleared(d, w) = win>0 ở index 99; IsWorldUnlocked(d, w): W1 luôn; W2 cần W1 cleared ở difficulty ≥ d …; RunRecord.AddRunRecord(RunRecordData). Compendium: RequestRecordSeenTowerCard/RecordTowerBuilt/RecordSeenRelic; JOURNAL_BUILT_TOWER_COUNT/USED_RELIC_COUNT. Block skin: RequestUnlockBlockSkin(type) → list_UnlockedBlockSkins; RequestSetBlockSkin → tetrisSkinType (TAB_BLOCK_SKIN trong customize).
