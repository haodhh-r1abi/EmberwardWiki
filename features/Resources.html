Mô tả

  • Ba lớp tiền: (1) Vàng (Coin) chỉ trong stage: đầu stage 50 (+talent), thưởng cuối vòng 30→100, kill quái, bán tháp; tiêu để xây/nâng tháp, rút bài, phá Bone wall; không mang sang stage (trừ lãi Merchant ≤150, talent Loot Scavenging đổi 50 vàng dư → 1/3/5 Ember Stone). (2) Ember Stone (gem) trong run: thưởng clear node (step+1)×5, quest ×5, extractor; tiêu ở Shop, Workshop (20/rune), Campsite, Altar. (3) EXP vĩnh viễn: thưởng clear node (step/2)*6+20 × hệ số độ khó (0.8/1.0/1.3), quest, Fast Learner; tiêu học talent. Ngoài ra: HP nguồn lửa, Gambler's Token (reroll), Revive item, Cosmo Shard (Mysterious Shard → Academy chest), Academy reroll count.
  • Coin: IngameData.Initialize(coin=50+talent+saved, hp, armor) → AddCoin/SetCoin qua event RequestAddCoin; OnCoinChanged. Cuối vòng cộng roundClearReward; cuối stage: goldRemainLastLevel (Merchant) và talent REMAIN_COIN_TO_GEM (1/3/5 gem mỗi 50 vàng, trừ vàng bán tháp CoinGainedFromSellTowerInThisRound). Gem: GameplayData.gem qua RequestAddGem; OnGemChanged cập nhật shop. EXP: PlayerLifetimeData.exp/lifetimeExpEarned qua RequestAddExp, ×GetDifficultyExpMultiplier; RequestLearnTalent trừ; ResetTalent hoàn toàn bộ. Reroll: GameplayData.rerollChance (đầu run 2 + talent) dùng ở chọn tháp/relic; Academy reroll: academyRerollCount +1/stage, +5 boss, vô hạn sau clear W5. Custom game: không EXP/record.

Lưu ý

📌 Chưa xác định: reviveItem (99999 trong một nhánh ctor) — có vẻ debug/custom; chưa thấy UI revive
📌 Chưa xác định: Fast Learner EXP param nằm ở talent chưa trong TalentSettingData (EXP_GAIN_INCREASE không có trong list 25)

Mở khóa & điểm vào

Điểm vào:

  • HUD coin/gem/HP
  • Talent page (EXP)
  • Journal stats (PlayerStats loc)

Cách hoạt động

  1. Nhận vàng: RequestAddCoin(value) → IngameData.AddCoin; GameplayStats.totalCoinsEarned, PlayerRecord.totalCollectedCoins → Gold Boost tile +50 %; DoubleCoin buff; Wealth Vault 10 % lãi ≤100/vòng; Gold Furnace 30/lượt; Statue of Greed/Poverty → Perk EXTRA_COIN +100 (Skeleton King) (Quy tắc: Shard Gold L2: thưởng vòng −30 %)
  2. Nhận Ember Stone: StageRewardData.Gem=(step+1)*5 → RequestAddGem → QuestSettingData.gemRewardMultiplier 5 (quest thưởng GEM) → Royal Command +10; Extractor +{0}/lượt; talent REMAIN_COIN_TO_GEM → OnGemChanged → UI shop giá mua được (Quy tắc: Gem về 0 khi run mới (GameplayData.gem=0))
  3. Nhận EXP: Exp node × GetDifficultyExpMultiplier (0.8/1.0/1.3) → Talent Fast Learner: +{0}/{1}/{2} nếu không mất máu (loc, param chưa rõ) → RequestAddExp → PlayerLifetimeData.exp, lifetimeExpEarned, PlayerRecord.totalExperience (Steam stat TOTAL_EXP)
  4. Gambler's Token (reroll): GetStartupRerollCount = 2 + talent TOWER_SELECT_REROLL (1/2/3) → Thưởng node: REROLL_CHANCE 1 (2 nếu step>3); endless REROLL_TOKEN → RequestAddRerollCount(−1); PlayerRecord.rerollCount (achievement REROLL_MORE_THAN_X)
  5. Academy reroll: ResourceManager.RerollAcademyCardSetData(original, index) → +1 charge mỗi stage clear, +5 khi hạ boss (ACADEMY_REROLL_LIMITATION) → Talent ACADEMY_FREE_CHOOSE (250 EXP): Royal Library — tự chọn 3 tháp/7 khối/1 relic
Luồng chi tiết theo code

Coin: IngameData.Initialize(coin=50+talent+saved, hp, armor) → AddCoin/SetCoin qua event RequestAddCoin; OnCoinChanged. Cuối vòng cộng roundClearReward; cuối stage: goldRemainLastLevel (Merchant) và talent REMAIN_COIN_TO_GEM (1/3/5 gem mỗi 50 vàng, trừ vàng bán tháp CoinGainedFromSellTowerInThisRound). Gem: GameplayData.gem qua RequestAddGem; OnGemChanged cập nhật shop. EXP: PlayerLifetimeData.exp/lifetimeExpEarned qua RequestAddExp, ×GetDifficultyExpMultiplier; RequestLearnTalent trừ; ResetTalent hoàn toàn bộ. Reroll: GameplayData.rerollChance (đầu run 2 + talent) dùng ở chọn tháp/relic; Academy reroll: academyRerollCount +1/stage, +5 boss, vô hạn sau clear W5. Custom game: không EXP/record.
