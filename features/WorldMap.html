Bản đồ run & node

Mỗi run là bản đồ node kiểu Slay-the-Spire: 8 bước (W1), 9 (W2–W4), 13 (W5 Void Depths) + node boss; mỗi bước 2–4 node, mỗi node nối 2 (95 %) hoặc 3 (5 %) node bước sau.

Mô tả

  • Mỗi run là bản đồ node kiểu Slay-the-Spire: 8 bước (W1), 9 (W2–W4), 13 (W5 Void Depths) + node boss; mỗi bước 2–4 node, mỗi node nối 2 (95 %) hoặc 3 (5 %) node bước sau. Bước 0 = ACADEMY (chọn bộ khởi đầu), bước cuối = BOSS; W5 có MID_BOSS bước 7 và bước 3/6/9 chỉ SHOP. Loại node: BATTLE (weight 5–10 ngẫu nhiên), BATTLE_CORRUPTED (15), BATTLE_ANOMALY (×1.5), BATTLE_DARKNESS (×1.25, Heroic), SHOP (100, step>5, cd 2), WORKSHOP (5, step>3, cd 3), ALTAR (5, cd 3), CAMPSITE (5), SPECIAL_EVENT/QUEST (0 — tắt), TREASURE, ROYAL_LIBRARY, SECRET_VAULT. 5 world: Misty Forest, Bone Desert, Frost Ruins, Sealed Citadel, Void Depths + Chaos Realm (mỗi battle map một vùng khác).
  • Map.GenerateMapData(setting): Random.InitState(seed); for step in 0..Step: số node Random(MinNodeInStep 2, MaxNodeInStep 4) (bước 0/cuối 1 node; isHaveRoyalPassTalent → 2 lựa chọn Academy/Library?); RollMapNodeType(setting, step, battleNodeOnly): step 0 → ACADEMY; step<4 chỉ battle cơ bản (chưa xong tutorial: step<5); từ step 2 thêm corrupted (cd 1), anomaly (unlock, cd), darkness; shop khi cd<1 && step>5; workshop cd<1 && step>3; campsite cd<1; chọn theo WeightedRandom rồi đặt cooldown (Shop 2, SpecialEvent 2, Workshop 3, Corrupted 1, Altar 3, Quest 3); mỗi bước giảm cooldown. CreateStageRewardData(type, step, isNodeBeforeBoss) gắn thưởng; AddAnomalyToMapNode cho node anomaly. GetRandomNumberOfConnections nối node; SetNodeRandomOffset bố trí; VisualizeMap tạo MapNode prefab theo MapNodePrefabData. Trạng thái node eMapNodeState: UNINITIALIZED, TOO_FAR, NOT_SELECTED, AVALIABLE, JUST_FINISHED, COMPLETED. Người chơi chọn node AVALIABLE → MapSceneProcess.CR_xxxNodeProc → hoàn thành → CR_UpdateMapNodeState, CR_AddNewStep (map lộ dần), save.

Lưu ý

📌 Chưa xác định: Node ROYAL_LIBRARY/SECRET_VAULT/CAMPSITE sinh ở đâu trong RollMapNodeType (campsite weight 5; library qua talent) chỉ đọc một phần
📌 Chưa xác định: Weight_Level random 5–10 so với Shop 100: shop gần như chắc chắn khi hết cooldown và step>5 (suy luận)

Mở khóa & điểm vào

W2 sau clear W1, W3 sau W2, W4 sau W3, W5 sau W4 (cùng độ khó hoặc cao hơn: IsWorldUnlocked duyệt difficulty 3→difficulty); Chaos Realm sau clear W5. Node anomaly/darkness/custom theo trang Perks/Difficulty.

Điểm vào:

  • MapScene sau khi chọn nhân vật/độ khó
  • Quay lại sau mỗi node (MapBlockCompleted)
  • Fog of war (MapSceneFogOfWarControl) mở dần theo bước

Cách hoạt động

  1. Sinh bản đồ: MapGenerateSetting(worldType, seed): Step = 8 + (1 nếu W2/W3/W4, 5 nếu W5); Min 2 / Max 4; Weight_Level = Random(5,10), Corrupted 15, Shop 100, Workshop 5, Altar 5, Campsite 5, SpecialEvent 0, Quest 0 → Map.GenerateMapData: vòng bước, RollMapNodeType, CreateStageRewardData, kết nối → MapData.list_MapNodeData, list_NodeCountInEachStep, IsGenerated (Quy tắc: Node bước 0 ACADEMY (11); bước cuối BOSS; W5: MI
  2. Chọn node và đi tiếp: MapNode.OnButtonClick → OnClickMapNodeButton → theo MapNodeType gọi CR_StartNodeProc/EventNodeProc/BattleNodeProc/BossNodeProc/ShopNodeProc/TreasureNodeProc/WorkshopNodeProc/CampsiteNodeProc/AcademyNodeProc/RoyalLibraryNodeProc/SecretVaultNodeProc/AltarNodeProc/QuestNodeProc → GameplayData.SetCurrentMapStep/SetCurrentMapNodeIndex; RecordMapNodeCleared → MapNode.SetCompleted; CR_ShowNodePath; fog
  3. Academy (bước 0): ResourceManager.GetAcademyCardSetData: 3 bộ cố định [Sentry 1066 + Lightning 1004 + Freeze 1006], [Dart 1007 + Cannon 1002 + Flamethrower 1003], [Torch 1049 + Drone 1011 + Lightning 1004] + 7 thẻ khối (TetrisStarterSetData) + relic; Chunk ép 2x2; Tiny bộ riêng → UI_MapScene_Academy_Popup: chọn 1 bộ; ACADEMY_REROLL (academyRerollCount; vô hạn sau W5) đổi bộ; CheckTowerSetDuplicate tránh trùng → Royal
  4. Treasure / Quest / Event node: TREASURE: CR_TreasureNodeProc → DiscoverRewardData_Map_Workshop → chọn thẻ (UI_DiscoverCard_Popup) → QUEST: UI_MapScene_Quest_Popup / UI_Obj_QuestBoard chọn thử thách cho stage sau (weight 0 ở map thường — dùng bởi Royal Command) → SPECIAL_EVENT: weight 0 (không sinh)
  5. Chaos Realm: Mỗi battle chọn scene từ world ngẫu nhiên (lastChaosRealmBossWorldType tránh lặp boss) → Music/fog W100 riêng (sprite_Fogmask_World100)
