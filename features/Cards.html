Mô tả

  • Trong stage người chơi có deck (list_DeckData) tạo từ kho thẻ khối/item (GameplayData.list_ItemStorage), tay bài (list_HandCardData, giới hạn itemCardLimit 10 + ExtraHandCardLimit) và chồng bỏ (list_DiscardData). Mỗi vòng tự rút 3 thẻ; rút thêm tốn vàng (5, +5 mỗi lần, có trần bởi talent Blueprint Study). Loại thẻ: PANEL (khối), BUFF, TOWER, WALL, COIN, HP, RELIC, RUNE, GEAR, REROLL. Thẻ có thể bị corrupt (Shard Player L3), ban, có giới hạn lượt dùng (cardUseCountLimit).
  • Vào stage: OnRequestResetDeckFromStorage → deck = clone kho, ShuffleDeck, drawCardCost = DRAW_CARD_COST_INITIAL (5). Round start: DrawCardFromDeck(drawCardPerRound=3 + talent Skilled Engineer 1/2 + Scholar 2 khối), hết deck → discard trộn lại. Draw thủ công: OnRequestDrawCard(count, doIncreaseDrawCost) trừ drawCardCost rồi IncreateDrawCost: +5 (Shard Gold L3: +2.5 thêm); nếu có relic giảm (×0.8 / ×0.6); talent CAPPED_DRAW_COST: trần = param(30/25/20)×1.5?; FreeDrawCardChance (relic/perk) bỏ phí. Hết vòng: RequestRemoveExcessHandCard nếu vượt limit; Shard Player L3 corrupt 1/3 tay. Thẻ item (IsItemCard) dùng xong ConsumeItemUseCount. Storage: thẻ khối thắng stage/shop/workshop vào list_ItemStorage; Workshop DISMANTLE cần ≥6 thẻ.

Mở khóa & điểm vào

Tutorial BUILD_TETRIS/BUFF_CARD. Mulligan (redraw đầu stage) cần talent STARTING_MULLIGAN; Royal Rune giữ thẻ luôn trong tay.

Điểm vào:

  • Nút Draw (DRAW_CARD) / phím
  • MULLIGAN đầu stage
  • DISCARD thẻ
  • OPEN_BACKPACK xem kho (VIEW_BACKPACK)

Cách hoạt động

  1. Rút bài đầu vòng: MainGame.CR_DrawCardAtRoundStart → RequestDrawCard(drawCardPerRound, false) → Tiny: chỉ khối ≤3 ô; Scholar: +2 khối; perk DRAW_EXTRA_CARD +1.. → OnRoundStartDrawCardComplete; Astral rune combo (Sun 5/Moon 4/Star 3 liên tiếp → thẻ tháp) (Quy tắc: Vượt hand limit → không rút (IsHandCardFull); CHEST_HAND_FULL)
  2. Rút bài trả vàng: OnRequestDrawCard(1, true) → AddCoin(−cost) hoặc ConsumeFreeDrawCard → IncreateDrawCost: cost += 5 (+2.5 Shard Gold L3); ×0.8/×0.6 relic; cap talent → OnDrawCardCostChanged cập nhật nút (Quy tắc: DRAW_CARD_COST_INITIAL 5, INCREASE 5; reset mỗi stage (OnRequestResetDrawCardCost))
  3. Mulligan: OnRequestMulligan → CR_Mulligan: trả tay về deck, xáo, rút lại → OnMulliganComplete (Quy tắc: 1 lần/stage)
  4. Bỏ thẻ / corrupt / ban: OnRequestDiscardCardFromHand → discard pile (Shapeshift rune: đổi hình rồi quay lại tay) → OnRequestCorruptHandCard: thẻ bị huỷ cuối vòng sau → OnRequestBanHandCard (perk ban)
  5. Kho thẻ giữa các stage: RequestAddTetrisCardToStorage(TetrisCardData) / RequestAddCardToStorage(itemType) → RequestRemoveCardFromStorage (workshop dismantle, ≥6) → UI_ChooseCardFromBackpack_Popup
Luồng chi tiết theo code

Vào stage: OnRequestResetDeckFromStorage → deck = clone kho, ShuffleDeck, drawCardCost = DRAW_CARD_COST_INITIAL (5). Round start: DrawCardFromDeck(drawCardPerRound=3 + talent Skilled Engineer 1/2 + Scholar 2 khối), hết deck → discard trộn lại. Draw thủ công: OnRequestDrawCard(count, doIncreaseDrawCost) trừ drawCardCost rồi IncreateDrawCost: +5 (Shard Gold L3: +2.5 thêm); nếu có relic giảm (×0.8 / ×0.6); talent CAPPED_DRAW_COST: trần = param(30/25/20)×1.5?; FreeDrawCardChance (relic/perk) bỏ phí. Hết vòng: RequestRemoveExcessHandCard nếu vượt limit; Shard Player L3 corrupt 1/3 tay. Thẻ item (IsItemCard) dùng xong ConsumeItemUseCount. Storage: thẻ khối thắng stage/shop/workshop vào list_ItemStorage; Workshop DISMANTLE cần ≥6 thẻ.
