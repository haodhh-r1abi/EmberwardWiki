Mô tả

  • Steamworks.NET (com.rlabrecque.steamworks.net): SteamManager singleton khởi tạo SteamAPI (DllCheck/Packsize test), RunCallbacks mỗi Update; dùng cho achievement/stat, leaderboard + Remote Storage UGC, avatar, wishlist (Obj_Wishlist), Steam Deck detect (isRunningOnSteamDeck → setting platform 5 = Steam Deck?), cloud save (ES3 file trong SaveData/, Steam Cloud do Steam client — không thấy ISteamRemoteStorage cho save). Bản Demo: SaveFile_Demo.sav, DEMO_PROGRESS_INHERITED chuyển tiến độ sang bản đầy đủ; tag Demo/Beta/Playtest ở logo.
  • Awake: Packsize/DllCheck → SteamAPI.RestartAppIfNecessary? → SteamAPI.Init; fail → log + UI_ShowSteamConnectionError; m_SteamAPIWarningMessageHook. Update: SteamAPI.RunCallbacks. AchievementManager/LeaderboardManager dùng Callback<T>. Demo: GameDataManager.IsDemoSaveFileExist → copy sang slot đầy đủ (ClearUsingDemoSaveFileFlag), TALENT_PAGE_UNLOCK_IN_FULL_VERSION, lockInDemoVersion/isInDemo flags trên SO.

Lưu ý

📌 Chưa xác định: Steam Cloud sync cấu hình ở Steamworks backend, không đọc được từ client
📌 Chưa xác định: Không thấy DLC/IAP nào (BillingMode.json chỉ là file mặc định Unity IAP)

Mở khóa & điểm vào

Điểm vào:

  • SteamManager.Awake (InitOnPlayMode)
  • UI_ShowSteamConnectionError khi init fail
  • CoinPage.OnClick_Wishlist

Cách hoạt động

  1. Khởi tạo Steam: Packsize Test / DllCheck Test → SteamAPI_Init(); fail → 'SteamAPI_Init() failed' + UI_ShowSteamConnectionError → s_EverInitialized chống init 2 lần
  2. Demo → Full: IsDemoSaveFileExist → load; DEMO_PROGRESS_INHERITED → DEMO_END_* popup cuối demo (wishlist/buy)
  3. Steam Deck / controller: isRunningOnSteamDeck → GetCurrentSettingPlatform (eSettingPlatform 5?) → Setting platform-specific (LockCursor 5, CursorSupportLine 5, AutoPauseOnLostFocus 3) → Rewired controller maps (Xbox/DualShock/…) trong MonoBehaviour assets
Luồng chi tiết theo code

Awake: Packsize/DllCheck → SteamAPI.RestartAppIfNecessary? → SteamAPI.Init; fail → log + UI_ShowSteamConnectionError; m_SteamAPIWarningMessageHook. Update: SteamAPI.RunCallbacks. AchievementManager/LeaderboardManager dùng Callback<T>. Demo: GameDataManager.IsDemoSaveFileExist → copy sang slot đầy đủ (ClearUsingDemoSaveFileFlag), TALENT_PAGE_UNLOCK_IN_FULL_VERSION, lockInDemoVersion/isInDemo flags trên SO.
