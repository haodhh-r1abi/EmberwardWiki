Độ khó & Inferno Shard

4 độ khó (eGameDifficultyType): CASUAL (hệ số 0.25, EXP ×0.8), NORMAL (0.75, ×1.0), HEROIC (1.88, ×1.3, mở sau hạ boss Normal; có Darkness stage), NIGHTMARE (enum, chưa có UI).

Mô tả

  • 4 độ khó (eGameDifficultyType): CASUAL (hệ số 0.25, EXP ×0.8), NORMAL (0.75, ×1.0), HEROIC (1.88, ×1.3, mở sau hạ boss Normal; có Darkness stage), NIGHTMARE (enum, chưa có UI). Inferno Shard (Hard mode): 9 loại shard (Fragility/Fatigue/Ferocity/Confusion/Malice/Depletion/Corruption/Nightmares/Void) mỗi loại 3 cấp gắn vào nguồn lửa; tổng cấp = difficulty level → quái HP +round(level×1.5) %, boss HP theo bảng, mở kỹ năng boss; kỷ lục highestInfernoShardLevel theo độ khó. Quái corrupted +20 % HP; mỗi relic +0.03 độ khó.
  • Chọn độ khó → GameplayData.difficulty; GetBaseDifficultyMultiplier dùng trong StageDataReader.GetCurrentDifficulty (nhân wave.difficultyMultiplier; Heroic giảm 0.75/0.8/0.9 theo stageLevel). HardModeSetting.list_HardModeSettingEntry (type, level 0–3); SetShardLevels; GetDifficultyLevel = tổng; GetMonsterHPMultiplier = round(level×1.5) (%); GetBossHPMultiplier tính riêng; GetPerkTypeByShardType → perk 7901+ kích hoạt ở MainGame.Start theo IsShardActivated(type, level). Shard Boss L1/2/3 → boss thêm kỹ năng (BOSS_SKILL_Wn_1..3). Kết thúc run: PlayerRecord.SetHighestInfernoShardLevel(level, difficulty).

Lưu ý

📌 Chưa xác định: GetBossHPMultiplier: bảng cộng theo shard (vòng lặp) chưa đọc số
📌 Chưa xác định: NIGHTMARE (3) có enum + StageRecord list nhưng chưa thấy nút UI

Mở khóa & điểm vào

Heroic: isDefeatedNormalModeBoss (SELECT_DIFFICULTY_HEROIC_LIMIT). Shard: IsInfernoShardSystemUnlocked(difficulty) = đã clear W5 (StageRecord index 99, world 16) ở độ khó đó trở lên; cấp shard n mở khi đã clear với tổng cấp ≥ n−1 (IsInfernoShardLevelUnlocked; UNLOCK_REQUIREMENT loc).

Điểm vào:

  • UI_DifficultySelection_Popup (CASUAL/NORMAL/HEROIC + shard panel)
  • GameplayData.SetHardModeSetting
  • Journal: highest shard level

Cách hoạt động

  1. Chọn độ khó: CASUAL/NORMAL luôn; HEROIC nếu isDefeatedNormalModeBoss → GameplayData.SetGameDifficulty; AnalyticsManager.RecordDifficulty → Heroic: DoSpawnDarknessLevel → node BATTLE_DARKNESS (Quy tắc: Casual/Normal/Heroic hệ số 0.25/0.75/1.88)
  2. Gắn Inferno Shard: Chọn cấp 0–3 cho từng shard (IsInfernoShardLevelUnlocked) → HardModeSetting.SetShardLevels(list) → GameplayData.hardModeData → UI: INFERNO_SHARD_LEVEL, MONSTER_HP_INCREASE +{0}%, BOSS_HP_INCREASE (Quy tắc: GetMaxDifficultyLevel = số shard × 3 (27))
  3. Hiệu ứng shard trong run: Fragility (HP): L1 heal chest −50 %, campsite/shop heal +35 %; L2 quái +1 dmg; L3 chỉ 3 HP → Fatigue (Cannon): L1 +20 % giá cùng loại/vòng; L2 malfunction +50 %; L3 deploy 5 s → Ferocity (Monster): L1 +tốc độ tới 30 % khi mất máu; L2 hồi 1 %/s sau 3 s không bị đánh; L3 quái lớn mạnh hơn → Confusion (Player): L1 skill tốn vàng; L2 khối thứ 3 twisted; L3 1/3 tay corrupt cuối vòng
  4. Kỷ lục: PlayerRecord.SetHighestInfernoShardLevel(level, difficulty) → Achievement WORLD_n_HEROIC_SHARD_CLEAR, ALL_HEROIC_SHARD_CLEAR → Journal JOURNAL_RECORD_HIGHEST_DIFFICULT_ONLY
Luồng chi tiết theo code

Chọn độ khó → GameplayData.difficulty; GetBaseDifficultyMultiplier dùng trong StageDataReader.GetCurrentDifficulty (nhân wave.difficultyMultiplier; Heroic giảm 0.75/0.8/0.9 theo stageLevel). HardModeSetting.list_HardModeSettingEntry (type, level 0–3); SetShardLevels; GetDifficultyLevel = tổng; GetMonsterHPMultiplier = round(level×1.5) (%); GetBossHPMultiplier tính riêng; GetPerkTypeByShardType → perk 7901+ kích hoạt ở MainGame.Start theo IsShardActivated(type, level). Shard Boss L1/2/3 → boss thêm kỹ năng (BOSS_SKILL_Wn_1..3). Kết thúc run: PlayerRecord.SetHighestInfernoShardLevel(level, difficulty).
