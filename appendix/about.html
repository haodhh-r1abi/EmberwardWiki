Về tài liệu này

Nguồn dữ liệu

  • Bản Steam PC của Emberward (ReficGames, Unity 2022.3.62f2, IL2CPP x64, 09/2026), export bằng tool PCExport: AssetRipper → project Unity; logic khôi phục từ GameAssembly.dll bằng Il2CppDumper (metadata) và Ghidra (pseudo-C của 19 538 method trong Asmdef_Emberward / Assembly-CSharp).
  • Số liệu thiết kế lấy từ ScriptableObject trong Resources/*data (tower, monster, stage, perk, relic, buffcard, rune, powergrid, gamesetting…) được flatten trong facts/so_assets.json, cùng Unity Localization (bảng String Table × 13 ngôn ngữ) và enum từ metadata.

Độ tin cậy

  • Số liệu không ghi chú là chép trực tiếp từ code/asset của client. "(suy luận)" = suy ra từ cách dùng; "(server)" = giá trị do server gửi lúc chạy, client chỉ có schema.
  • Mỗi use case có cột Evidence là tên method thật; mở file .c tương ứng trong RecoveredNative/PseudoC để đối chiếu.

Cách cập nhật

  1. Sửa/thêm file GameDesign/gdd/<Feature>.json theo gdd/SCHEMA.md và metadata trang trong site_meta/<Feature>.json.
  2. Chạy python tools/gd_site.py để sinh lại thư mục site/; python tools/gd_xlsx.py cho bản Excel.
  3. Đẩy thư mục site/ lên GitHub và bật Pages.

Tài liệu chỉ dùng nội bộ cho mục đích nghiên cứu thiết kế.

Tài liệu thiết kế đọc ngược từ client Emberward Steam build 2026-09 (Unity 2022.3.62f2, IL2CPP x64, ReficGames) · sinh tự động từ GameDesign/gdd/*.json bằng tools/gd_site.py · chỉ dùng nội bộ.
